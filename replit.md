# Photo Gallery

This is a plain HTML, CSS, and JavaScript project with no package dependencies or build step.

## Run

The **Start application** workflow serves the project on port 5000 with:

```sh
python3 -m http.server 5000 --bind 0.0.0.0
```

Open the Replit Preview to view the gallery. Changes to `index.html`, `styles.css`, or `script.js` are available after refreshing the preview.
